## Circle Quest visual lessons (2026-08-10, from circle-geometry-game PROJECT-STATUS.md —
## binding on ALL sessions below that draw diagrams)

- **Angle labels carry an explicit distance from their vertex, ~33–46 px.** Bare defaults
  let narrow wedges push the label 60–86 px out (the 2026-07-24 CQ label fix). Every new
  figure API takes/uses an explicit label radius.
- **Label collisions are found by measurement, not by eye:** a pairwise gap scan over the
  computed label coordinates (the CQ method). Any generator whose two labels can land
  within ~18 px of each other must pull them in to hug their vertices.
- **The asked angle NEVER shows its value on the figure** — the diagram must not hand over
  the answer (CQ s6p5 ruling). Given angles show values; the unknown shows its letter.
- **Decorative marks (tick marks, pyltjies, blokkie) are drawn from separate options and
  never move any geometry** (CQ's {mk:"t1"|"p1"} pattern — purely decorative).
- **verify page:** Session 2 builds tools/verify-stellings.html (+ node runner) on the
  pattern of circle-geometry-game's verify-daily.html + tools/verify-node.mjs: walk every
  ch6 skill's gen() many times, render the figure, MEASURE rendered angles against the
  question's maths and label distances against the 33–46 px rule — 0 mismatches required.
  The page renders every question with its figure and answer so it doubles as Megan's
  click-through review preview. Sessions 3–5 extend it to their new rounds (Session 5 adds
  the quad figures). It is a repo tool page like CQ's — committed, never linked from the
  learner UI.
